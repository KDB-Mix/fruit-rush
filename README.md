# Fruit rush
-# this is my first game with pygame so dont expect much

___
You are a basket trying to catch as much fruits falling from the tree as possible.

You drop 3, you lose, so be careful

___
If you want to edit it, make sure that you have git installed, and run this in the 'git cmd' app or the terminal:

`git clone https://github.com/KDB-Mix/fruit-rush`

You will have a folder named `fruit-rush` in the place where you ran the command from (default in windows is C:/Users/your-username)

Then make sure that you have python installed and correctly setup

Install the dependecies:

`pip install pygame-ce platformdirs`

To run the game on your machine, in the terminal, run `main.py`

To build it, go to the repo folder:

`cd fruit-rush`

Make sure that you have pyinstaller installed:

`pip install pyinstaller`

and run:

`pyinstaller mian.spec`

The compiled file will appear in `dist` and the result binary type (wiondows, mac, linux) depends on your os
